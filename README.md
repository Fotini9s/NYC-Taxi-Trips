# NYC-Taxi-Trips
# NYC Taxi Trips – Fare, Duration & Tipping Behaviour

## Project Overview
SQL analysis of NYC taxi trip data to explore fare patterns, demand by hour, payment types, and tipping behaviour.

## Dataset
wagon-bootcamp-497711.nyc_taxi_trips.nyc_taxi_trips_clean_data

## Analyses Included
- Fare vs Demand
- Tipping vs Distance
- Payment Type Label
- Tip Integrity Check

## Skills Demonstrated
SQL (CASE WHEN, GROUP BY, ORDER BY, aggregation), data cleaning, exploratory analysis.

## Repo Structure
- fare_vs_demand.sql
- tipping_vs_distance.sql
- payment_type_label.sql
- tip_integrity_check.sql

## Notes
Cash tips are unreliable → tipping analysis uses credit card trips only.

## Summary
This project demonstrates practical SQL cleaning, KPI analysis, and tipping‑behaviour insights using a real NYC taxi dataset.
